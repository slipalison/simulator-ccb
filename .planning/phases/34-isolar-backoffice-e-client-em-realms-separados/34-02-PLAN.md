<task>
  <description>Configure Dual JWT Bearer Authentication</description>

  </read_first>

    In `Program.cs`, replace `builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme).AddJwtBearer(...)` with:
    ```csharp
    builder.Services.AddAuthentication()
        .AddJwtBearer("BearerBackoffice", options => {
            options.Authority = builder.Configuration["Keycloak:BackofficeRealmUrl"];
            // Other settings
        })
        .AddJwtBearer("BearerClient", options => {
            options.Authority = builder.Configuration["Keycloak:ClientRealmUrl"];
            // Other settings
        });

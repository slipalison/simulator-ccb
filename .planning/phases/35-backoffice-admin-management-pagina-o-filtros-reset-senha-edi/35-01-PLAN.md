<title>Implement Deactivate & Reactivate Administrator Commands</title>
<requirements>MGMT-05, MGMT-06, SEC-01, SEC-05, AUD-06</requirements>
<read_first>
- src/Onboarding.API/Controllers/AdminUserController.cs

<action>
Create `DeactivateAdministratorCommand.cs` and `ReactivateAdministratorCommand.cs` and their handlers.
In Deactivate, check if the user is the last active admin. If `true`, throw `InvalidOperationException` (SEC-05).
Deactivate: call Keycloak to set `Enabled = false`, and force session termination (`LogoutAll` or equivalent).

Audit both operations with `IAuditService` (AUD-06).

</action>

</acceptance_criteria>
</task>

# Phase 12 — Plan 01: shadcn/ui Setup + Theme Infrastructure

## Objective

Instalar e configurar shadcn/ui no projeto Vinxi, criar a infraestrutura de tema (ThemeProvider, ThemeToggle) e preparar os componentes base para o redesign das telas.

**Requisitos atendidos:** UI-01, UI-02

## Execution Context

### Current State
- **Tailwind CSS v4:** Já instalado (`tailwindcss@4.2.2` com `@tailwindcss/vite`)
- **React Hook Form + Zod:** Já instalados (`react-hook-form@7.72.1`, `zod@4.3.6`, `@hookform/resolvers@5.2.2`)
- **Radix UI primitives:** Já instalados (`@radix-ui/react-label`, `@radix-ui/react-slot`)
- **Utility libs:** `class-variance-authority`, `clsx`, `tailwind-merge`, `tw-animate-css` — já presentes
- **lucide-react:** Já instalado (`lucide-react@1.7.0`) — icons prontos
- **Componentes existentes:** `AppButton.tsx`, `LabeledField.tsx`, `ExampleForm.tsx`, `PageLayout.tsx` — serão substituídos

### Dependencies
- **next-themes:** Não instalado — necessário para ThemeProvider
- **shadcn/ui CLI:** Não instalado — necessário para scaffold de componentes
- **Vinxi:** Funciona com `next-themes` (React-only, sem necessidade de Next.js)

### Technical Approach
```
1. Instalar next-themes
2. Rodar npx shadcn@latest init — gera components.json
3. Instalar componentes base via shadcn: button, input, label, card, form, radio-group, alert, toast, skeleton, badge, separator, dropdown-menu
4. Criar globals.css com CSS variables para light/dark themes
5. Criar ThemeProvider.tsx com next-themes
6. Criar ThemeToggle.tsx com botão sol/lua
7. Integrar ThemeProvider no app root (main.tsx)
8. Test: toggle funciona, persiste, detecta prefers-color-scheme
```

### Risks & Mitigations
- **shadcn/ui incompatível com Vinxi:** shadcn é agnóstico ao framework — componentes são React puro. Se falhar, copiar manualmente de https://ui.shadcn.com/docs
- **Tailwind v4 conflito:** shadcn suporta Tailwind v4. Se houver problema, ajustar `components.json` com `tailwind.config` path correto
- **Flash de tema no reload:** Usar `suppressHydrationWarning` no `<html>` + CSS `transition-colors` no body

### Task 12.1.2: Theme Provider + Theme Toggle

**Objective:** Criar infraestrutura de tema com toggle dark/light

**Actions:**

1. **Criar `frontend/src/lib/theme-provider.tsx`:**
   ```tsx
   "use client"
   import * as React from "react"
   import { ThemeProvider as NextThemesProvider } from "next-themes"

   export function ThemeProvider({ children, ...props }: React.ComponentProps<typeof NextThemesProvider>) {
     return <NextThemesProvider {...props}>{children}</NextThemesProvider>
   }
   ```

2. **Criar `frontend/src/components/atoms/ThemeToggle.tsx`:**
   ```tsx
   import { useTheme } from "next-themes"
   import { Moon, Sun } from "lucide-react"
   import { Button } from "@/components/ui/button"

   export function ThemeToggle() {
     const { theme, setTheme } = useTheme()

     return (
       <Button
         variant="ghost"
         size="icon"
         onClick={() => setTheme(theme === "light" ? "dark" : "light")}
       >
         <Sun className="h-[1.2rem] w-[1.2rem] rotate-0 scale-100 transition-all dark:-rotate-90 dark:scale-0" />
         <Moon className="absolute h-[1.2rem] w-[1.2rem] rotate-90 scale-0 transition-all dark:rotate-0 dark:scale-100" />
         <span className="sr-only">Toggle theme</span>
       </Button>
     )
   }
   ```

3. **Modificar `frontend/src/main.tsx` — Envolver app com ThemeProvider:**
   ```tsx
   import { ThemeProvider } from "./lib/theme-provider"
   import { AuthProvider } from "./lib/auth-context"

   // No app root:
   <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
     <AuthProvider>
       <RouterProvider router={router} />
     </AuthProvider>
   </ThemeProvider>
   ```

4. **Modificar `frontend/src/globals.css` — Adicionar transição suave:**
   ```css
   @layer base {
     * {
       @apply border-border;
     }
     body {
       @apply bg-background text-foreground;
       transition-colors 0.2s ease-in-out;
     }
   }
   ```

5. **Modificar `frontend/index.html` — Adicionar `suppressHydrationWarning`:**
   ```html
   <html lang="pt-BR" suppresshydrationwarning>
   ```

6. **Criar `frontend/src/tests/theme-provider.test.tsx`:**
   ```tsx

     it('toggle to dark — applies .dark class on html', () => { /* test */ });

   ```

7. **Criar `frontend/src/tests/theme-toggle.test.tsx`:**

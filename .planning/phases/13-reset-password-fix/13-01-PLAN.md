## Context

### The Problem (P0 from v2.0 Audit)

In `ForgotPasswordCommandHandler.cs` line 55:
```csharp
var resetLink = $"http://localhost:3001/reset-password?token={token.Token}";
```

The frontend runs on port **5173** (Vinxi), not 3001. When a user clicks the reset link in the email, they land on a non-existent server. The forgot → reset → login flow is broken end-to-end.

### The Fix

1. Inject `IConfiguration` into `ForgotPasswordCommandHandler`
2. Read `Frontend:BaseUrl` with fallback to `http://localhost:5173`
3. Build reset link dynamically: `$"{frontendBaseUrl}/reset-password?token={token.Token}"`
4. Document env var in `.env.example` and `compose.yaml`
5. Add integration test to verify reset link contains correct base URL

### What Already Works
- `PasswordResetToken.cs` — 15-min expiry, factory method
- `ResendEmailService.cs` — sends emails via Resend.com API
- `ResetPasswordCommand.cs` — validates token, updates Keycloak password
- Frontend `ResetPasswordPage.tsx` — reads `?token=` from URL, form with strength meter
- Frontend `ForgotPasswordPage.tsx` — email input, calls API

### What Doesn't Work
- Reset link in email points to wrong port (3001 instead of 5173)

### Task 13.1.2: GREEN — Inject IConfiguration + Use Frontend:BaseUrl

**Objective:** Make `ForgotPasswordCommandHandler` use configurable frontend base URL.

1. **Modify `src/Onboarding.Application/Auth/Commands/ForgotPasswordCommand.cs`:**

Add `IConfiguration` as a constructor dependency:

```csharp
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.Logging;
// ... existing imports

public sealed class ForgotPasswordCommandHandler : ICommandHandler<ForgotPasswordCommand, Unit>
{
    private readonly IPasswordResetTokenRepository _tokenRepo;
    private readonly IKeycloakUserService _keycloakService;
    private readonly IEmailService _emailService;
    private readonly IConfiguration _configuration;
    private readonly ILogger<ForgotPasswordCommandHandler> _logger;

    public ForgotPasswordCommandHandler(
        IPasswordResetTokenRepository tokenRepo,
        IKeycloakUserService keycloakService,
        IEmailService emailService,
        IConfiguration configuration,
        ILogger<ForgotPasswordCommandHandler> logger)
    {
        _tokenRepo = tokenRepo;
        _keycloakService = keycloakService;
        _emailService = emailService;
        _configuration = configuration;
        _logger = logger;
    }
```

2. **Replace hardcoded URL (line 55):**

```csharp
// BEFORE:
var resetLink = $"http://localhost:3001/reset-password?token={token.Token}";

// AFTER:
var frontendBaseUrl = _configuration["Frontend:BaseUrl"] ?? "http://localhost:5173";
// Remove trailing slash if present
frontendBaseUrl = frontendBaseUrl.TrimEnd('/');
var resetLink = $"{frontendBaseUrl}/reset-password?token={token.Token}";
```

3. **Verify DI wiring:** The handler is registered in Application layer DI. `IConfiguration` is available via built-in .NET DI — no changes needed to registration code since `IConfiguration` is a framework-provided service.

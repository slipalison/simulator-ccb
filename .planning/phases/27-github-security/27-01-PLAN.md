## Technical Details

### `.github/SECURITY.md`

```markdown
# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Main branch | ✅ Yes |

## Reporting a Vulnerability

Please report security vulnerabilities privately through:

1. **GitHub Security Advisories** — Go to Security → Advisories → New draft security advisory
2. **Email** — [security contact if available]

**Do NOT** report vulnerabilities via public issues or pull requests.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Assessment**: Within 1 week
- **Fix**: Within 2 weeks for critical issues
- **Public disclosure**: After fix is deployed and users have time to update

## Security Measures

This project uses automated security scanning in CI:

| Tool | Scans For |
|------|-----------|
| Semgrep | Code patterns (XSS, CSRF, insecure deserialization) |
| CodeQL | Dataflow and taint analysis |
| Trivy (fs) | Dependency vulnerabilities (CVEs) |
| Trivy (image) | Container image vulnerabilities |
| Dockle | Docker image best practices |
| Checkov | Infrastructure as Code misconfigurations |
| Kubescape | Kubernetes security policies |
| Gitleaks | Hardcoded secrets (pattern matching) |
| TruffleHog | Hardcoded secrets (active verification) |
| Dependabot | Automated dependency updates |
```

### Branch Protection Documentation

Document the exact steps for configuring branch protection on `main`:

1. Navigate to **Settings → Branches → Branch protection rules**
2. Click **Add rule** or edit existing `main` rule
3. Pattern: `main`
4. Check **"Require status checks to pass before merging"**
5. Search and add each required check by name
6. Check **"Require branches to be up to date before merging"**
7. Save

Required status checks list:
- `Backend (.NET 10)`
- `Frontend Client (Vinxi)`
- `Frontend Backoffice (Vinxi)`
- `SAST — Semgrep`
- `SAST — CodeQL`
- `SCA — Trivy`
- `Container Scan — Trivy Image`
- `Container Lint — Dockle`
- `IaC — Checkov`
- `Secrets — Gitleaks`
- `Secrets — TruffleHog`

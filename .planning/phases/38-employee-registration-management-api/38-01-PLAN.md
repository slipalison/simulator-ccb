## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → POST /api/companies/registration | Untrusted input — CNPJ, email, password, terms acceptance |
| Client → GET /api/companies/me | Authenticated (BearerClient scheme) — protected route |
| Admin → GET/PUT /api/admin/companies | Admin-only (BearerBackoffice + role=admin) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-01 | Spoofing | POST /api/companies/registration | mitigate | Password policy validation matches Keycloak rules (8+ chars, upper, lower, digit, special) |
| T-38-02 | Tampering | POST /api/companies/registration | mitigate | FluentValidation on all fields; CNPJ check-digit validation via Cnpj.Create() |
| T-38-03 | Repudiation | All company mutations | mitigate | IAuditService.RecordAsync for CompanyRegistered and CompanyUpdated |
| T-38-04 | Information Disclosure | Duplicate CNPJ check | mitigate | Return generic 409 "A company with this CNPJ already exists" — does NOT reveal which company |
| T-38-05 | Denial of Service | Keycloak user creation failure | mitigate | Compensation: delete Company row from DB if Keycloak fails |
| T-38-06 | Elevation of Privilege | GET /api/admin/companies | mitigate | [Authorize(Roles = "admin")] on AdminUserController — already enforced |

# 10-01: Profile API Client, Types, and Component Skeleton

## Objective

Create the data layer and Atomic Design component skeleton needed for the Profile UI. This includes the API client for fetching profile data, shared TypeScript types matching the backend DTO, and the base profile components (atoms + molecule) with RED test stubs.

## Context

The backend `GET /api/clients/me` endpoint is fully functional with `[Authorize]` middleware. It reads the `email` claim from the JWT, looks up the client via `IClientRepository`, and returns a `ClientProfileDto`:

```csharp
public sealed record ClientProfileDto(
    Guid Id,
    string Name,
    string Email,
    string Phone,
    string Type,       // "PessoaFisica" or "PessoaJuridica"
    string? Cpf,       // null for PJ
    string? Cnpj,      // null for PF
    string? RazaoSocial // null for PF
);
```

The frontend `AuthContext` exposes `getAccessToken()` which returns the in-memory JWT (never persisted to localStorage — SEC-10). No component currently uses this method.

Existing API clients in `api.ts` follow this pattern:
- Standalone async function
- Uses `ky` or `fetch` with Authorization header
- Custom error class for failures
- Typed response

### Task 2: Add profile API client
**File:** `frontend/src/lib/api.ts` (update)

Add two new exports to the existing api.ts:

```typescript
// Custom error class for profile fetch failures
export class ProfileError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'ProfileError';
  }
}

// Fetch current user's profile using Bearer token from AuthContext
export async function getProfileClient(): Promise<ClientProfileDto> {
  // Import tokens dynamically to avoid circular dependencies
  const { getAccessToken } = await import('./auth-context');
  const token = getAccessToken();

  if (!token) {
    throw new ProfileError('No authentication token available');
  }

  const response = await fetch('/api/clients/me', {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json',
    },
  });

  if (!response.ok) {
    if (response.status === 401) {
      throw new ProfileError('Authentication required');
    }
    throw new ProfileError('Failed to fetch profile data');
  }

  return response.json();
}
```

**Pattern note:** Use dynamic `import()` for `getAccessToken` to avoid circular dependency issues (api.ts → auth-context.tsx → api.ts).

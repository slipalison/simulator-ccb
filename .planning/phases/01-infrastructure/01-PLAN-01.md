Create `compose.yaml` at the repo root. Implement all five services exactly per the research
patterns. Critical requirements for each service:

**app_db:**
- Image: `postgres:16-alpine`
- Env: `POSTGRES_DB=onboarding`, `POSTGRES_USER=appuser`, `POSTGRES_PASSWORD=${APP_DB_PASSWORD}`
- Volume: `app_data:/var/lib/postgresql/data`
- Port: `"127.0.0.1:5432:5432"` (loopback bind — security requirement)
- Healthcheck: `pg_isready -U appuser -d onboarding`, interval 10s, timeout 5s, retries 5, start_period 30s

**keycloak_db:**
- Image: `postgres:16-alpine`
- Env: `POSTGRES_DB=keycloak`, `POSTGRES_USER=kcuser`, `POSTGRES_PASSWORD=${KC_DB_PASSWORD}`
- Volume: `keycloak_data:/var/lib/postgresql/data`
- NO host port exposure (internal Docker network only — keycloak_db must not be reachable from host)
- Healthcheck: `pg_isready -U kcuser -d keycloak`, interval 10s, timeout 5s, retries 5, start_period 30s

**keycloak:**
- Image: `quay.io/keycloak/keycloak:26.1`
- Command: `["start-dev", "--import-realm"]`
- Env (critical — Keycloak 26.x variable names):
  - `KC_BOOTSTRAP_ADMIN_USERNAME: admin` (NOT KEYCLOAK_ADMIN — that's the old name, silently ignored in 26.x)
  - `KC_BOOTSTRAP_ADMIN_PASSWORD: ${KC_ADMIN_PASSWORD}`
  - `KC_DB: postgres`
  - `KC_DB_URL: jdbc:postgresql://keycloak_db:5432/keycloak`
  - `KC_DB_USERNAME: kcuser`
  - `KC_DB_PASSWORD: ${KC_DB_PASSWORD}`
  - `KC_HEALTH_ENABLED: "true"` (required — exposes /health/ready on management port 9000)
  - `KC_HTTP_ENABLED: "true"`
  - `KC_HOSTNAME_STRICT: "false"`
  - `KC_HOSTNAME: http://localhost:8180`
- Volume: `./keycloak/onboarding-realm.json:/opt/keycloak/data/import/onboarding-realm.json:ro`
  (realm JSON file will be created in Plan 02)
- Port: `"127.0.0.1:8180:8080"` (container 8080 → host 8180, loopback only)
- depends_on: `keycloak_db: condition: service_healthy`
- Healthcheck (NO curl — it's not in the Keycloak 26.x image):
```yaml
test: ["CMD-SHELL", "exec 3<>/dev/tcp/127.0.0.1/9000 && echo -e 'GET /health/ready HTTP/1.1\\r\\nHost: localhost\\r\\nConnection: close\\r\\n\\r\\n' >&3 && cat <&3 | grep -q '200 OK'"]
interval: 15s
timeout: 10s
retries: 10
start_period: 60s
```

**api:**
- Build: `context: .`, `dockerfile: src/Onboarding.API/Dockerfile`
- Env:
  - `ASPNETCORE_ENVIRONMENT: Development`
  - `ASPNETCORE_HTTP_PORTS: "8080"`
  - `ConnectionStrings__AppDb: Host=app_db;Port=5432;Database=onboarding;Username=appuser;Password=${APP_DB_PASSWORD}`
  - `Keycloak__Authority: http://keycloak:8080/realms/onboarding`
  - `Keycloak__AdminClientId: onboarding-api-admin`
  - `Keycloak__AdminClientSecret: ${KC_ADMIN_CLIENT_SECRET}`
  - `Keycloak__RealmUrl: http://keycloak:8080/realms/onboarding`
  - `Keycloak__ValidIssuer: http://localhost:8180/realms/onboarding`
- Port: `"127.0.0.1:8080:8080"`
- depends_on: `app_db: condition: service_healthy` AND `keycloak: condition: service_healthy`
- Healthcheck: `curl -f http://localhost:8080/healthz || exit 1`, interval 10s, timeout 5s, retries 5, start_period 30s

**frontend:**
- Build: `context: ./frontend`, `dockerfile: Dockerfile`
- Env:
  - `VITE_API_URL: http://localhost:8080`
  - `VITE_KEYCLOAK_URL: http://localhost:8180`
  - `VITE_KEYCLOAK_REALM: onboarding`
  - `VITE_KEYCLOAK_CLIENT_ID: onboarding-app`
- Port: `"127.0.0.1:5173:5173"`
- depends_on: `api: condition: service_healthy`

**Volumes block:**
```yaml
volumes:
  app_data:
  keycloak_data:
```

**Networks block (explicit name for discoverability):**
```yaml
networks:
  default:
    name: onboarding-net
```

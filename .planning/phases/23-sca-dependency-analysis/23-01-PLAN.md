# Plan 23-01 — Dependabot Configuration + Auto-Merge Policy + Weekly Update Schedule

## Overview

Configure GitHub Dependabot para monitorar vulnerabilidades em dependências NuGet, npm, Docker e GitHub Actions. Dependabot abre PRs automáticos quando detecta updates de pacotes com vulnerabilidades conhecidas.

## Success Criteria

1. ✅ `.github/dependabot.yml` exists with 4 ecosystem entries: nuget, npm, docker, github-actions
2. ✅ Weekly schedule configured (runs on Monday UTC)
3. ✅ Version update PRs include auto-generated changelogs and security labels
4. ✅ `frontend/client/package-lock.json` monitored
5. ✅ `frontend/backoffice/package-lock.json` monitored
6. ✅ `Onboarding.slnx` (all .csproj files) monitored
7. ✅ Docker images in `compose.yaml` monitored

## Scope

### In Scope
- `.github/dependabot.yml` — all 4 ecosystem configurations
- Review `compose.yaml` for Docker images that Dependabot should monitor
- Review `.github/workflows/ci.yml` for GitHub Actions to monitor

### Out of Scope
- Auto-merge configuration — requires GitHub repository settings, handled via repository rules
- Trivy filesystem scanning — handled in Plan 23-02
- Manual dependency updates — not automated by Dependabot

## Technical Details

### Dependabot Configuration

```yaml
version: 2
updates:
  # NuGet packages (.NET 10 backend)
  - package-ecosystem: "nuget"
    directory: "/"
    schedule:
      interval: "weekly"
      day: "monday"
    open-pull-requests-limit: 10
    commit-message:
      prefix: "chore(deps)"
    labels:
      - "dependencies"
      - "nuget"
    groups:
      non-major:
        patterns:
          - "*"
        update-types:
          - "minor"
          - "patch"

  # npm packages (frontend client)
  - package-ecosystem: "npm"
    directory: "/frontend/client"
    schedule:
      interval: "weekly"
      day: "monday"
```

## Tasks

### Task 1: Create `.github/dependabot.yml`
**What:** Create Dependabot configuration with 5 entries: nuget (root), npm (frontend/client), npm (frontend/backoffice), docker (root), github-actions (root). Weekly schedule, Monday UTC.
**Test approach:** Validate YAML syntax. Verify all 5 ecosystems present. Verify directories are correct.
**Validation:** File exists at `.github/dependabot.yml`. Contains nuget, npm (x2), docker, github-actions. All schedules weekly on Monday.

### Task 2: Verify Docker images are monitorable
**What:** Check `compose.yaml` for Docker image references. Dependabot monitors Dockerfiles and `compose.yaml` files that use `image:` directives.
**Test approach:** Review compose.yaml — verify FROM statements in Dockerfiles use pinned versions or tags (not `latest`). Verify compose.yaml image references are valid.
**Validation:** All Docker images use specific tags (e.g., `postgres:16-alpine`, `quay.io/keycloak/keycloak:26.1`). No `latest` tags.

### Task 3: Validate Dependabot configuration
**What:** Push `.github/dependabot.yml` to a branch. Go to repository Settings → Code security → Dependabot alerts. Verify it's enabled. Check that Dependabot detects the configuration.
**Test approach:** Push to feature branch. Wait for Dependabot to run (or use "Run now" button in GitHub UI). Check Dependabot tab in Security settings.
**Validation:** Dependabot reports "Last checked" timestamp. No configuration errors.

## Task Order

Sequential:
- **Task 1:** Create dependabot.yml
- **Task 2:** Verify Docker images (parallel with Task 1)
- **Task 3:** Validate configuration (depends on Tasks 1-2)

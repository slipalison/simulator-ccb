## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → Employee API | All actions use companyId from auth context (server-validated) — prevents cross-company access |
| Client → Keycloak | Access group changes synced to Keycloak (PERM-04) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-08 | Tampering | Employee actions | mitigate | companyId from auth context, not URL params — backend enforces company isolation (PERM-05) |
| T-40-09 | Elevation | Viewer seeing actions | mitigate | UI hides actions for viewer (UX), backend enforces permission policy (PERM-02) — defense in depth |
| T-40-10 | Repudiation | LGPD deletion confirmation | mitigate | Email confirmation requirement prevents accidental deletion |
| T-40-11 | Info disclosure | Temporary password | mitigate | One-time reveal, modal cannot be reopened, not stored in any browser storage |
</threat_model>

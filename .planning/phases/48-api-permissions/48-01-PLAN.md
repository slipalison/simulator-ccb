**Error handling pattern** (use explicit try/catch in each mutation endpoint, consistent with CompaniesController pattern):
```csharp
try
{
    var command = new RegisterXCommand(...actor info from claims...);
    var validation = await _validator.ValidateAsync(command, ct);
    if (!validation.IsValid)
        return UnprocessableEntity(new ValidationProblemDetails(
            validation.Errors.GroupBy(e => e.PropertyName)
                .ToDictionary(g => g.Key, g => g.Select(e => e.ErrorMessage).ToArray())));
    
    var result = await _handler.HandleAsync(command, ct);
    return CreatedAtAction(nameof(GetX), new { id = result.Id }, result);
}
catch (DuplicateEntityException ex)
{
    return Conflict(new ProblemDetails { Title = "Conflict", Status = 409, Detail = ex.Message });
}
catch (KeyNotFoundException)
{
    return NotFound();
}
```

**ProducesResponseType attributes** — add for each endpoint following CompaniesController/AdminUserController pattern (200OK for GET, 201Created for POST, 204NoContent for PUT, 404NotFound, 409Conflict, 422UnprocessableEntity for validation errors).

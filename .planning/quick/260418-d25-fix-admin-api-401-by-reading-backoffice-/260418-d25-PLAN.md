<objective>
Corrigir o erro 401 retornado por todas as rotas `/api/admin/*` (exceto `/api/admin/auth/*`) após a migração do backoffice para Auth Code Flow + PKCE (Phase 33).

**Causa raiz:** `AdminSessionMiddleware` ainda procura o cookie legado `adminRefreshToken` (ROPC). O Vinxi auth-server passou a setar `backoffice_access_token` (JWT já válido) e `backoffice_refresh_token`. O middleware nunca encontra o cookie esperado, pula o processamento, e `[Authorize(Roles = "admin")]` falha em todos os browsers.

**Estratégia:** O cookie `backoffice_access_token` JÁ é um JWT emitido pelo Keycloak via ACF+PKCE — basta lê-lo do cookie e setar `Authorization: Bearer <token>`. Toda lógica de refresh/exchange de token sai do middleware (já é responsabilidade do Vinxi via `/auth/refresh`). Como bônus, removemos o `AdminAuthController` ROPC legado, que virou dead code após o frontend migrar para ACF.

Purpose: Restaurar o acesso a `/api/admin/users`, `/api/admin/administrators`, `/api/admin/audit-log` para administradores autenticados via ACF.

Output:
- `AdminSessionMiddleware` simplificado, lendo `backoffice_access_token`.
- `AdminAuthController` removido (dead code ROPC).
- Suíte de testes ajustada e verde.
</objective>

    ```csharp
    using Microsoft.AspNetCore.Http;

    namespace Onboarding.API.Middleware;

    /// <summary>
    /// Admin session middleware — converte o cookie httpOnly backoffice_access_token
    /// (JWT emitido pelo Keycloak via Auth Code Flow + PKCE) em header Authorization: Bearer
    /// para que [Authorize(Roles = "admin")] funcione nos endpoints /api/admin/*.
    ///
    /// O cookie é setado pelo auth-server Vinxi (frontend/backoffice/auth-server.ts) após
    /// /auth/callback. A rotação do access token é responsabilidade do Vinxi via /auth/refresh
    /// — este middleware NÃO chama Keycloak nem manipula cookies.
    ///
    /// Roda ANTES de UseAuthentication para que o JwtBearer veja o header populado.
    /// </summary>
    public static class AdminSessionMiddleware
    {
        private const string AccessTokenCookieName = "backoffice_access_token";

        public static IApplicationBuilder UseAdminSession(this IApplicationBuilder app)
        {
            return app.Use(async (context, next) =>
            {
                var path = context.Request.Path;
                var logger = context.RequestServices.GetRequiredService<ILoggerFactory>()
                    .CreateLogger("AdminSessionMiddleware");

                if (!path.StartsWithSegments("/api/admin"))
                {
                    await next();
                    return;
                }

                if (!context.Request.Cookies.TryGetValue(AccessTokenCookieName, out var accessToken)
                    || string.IsNullOrEmpty(accessToken))
                {
                    logger.LogDebug("AdminSessionMiddleware: no {Cookie} cookie on {Path}",
                        AccessTokenCookieName, path);
                    await next();
                    return;
                }

                context.Request.Headers.Authorization = $"Bearer {accessToken}";
                logger.LogInformation("AdminSessionMiddleware: forwarded access token from cookie on {Path}",
                    path);

                await next();
            });
        }
    }
    ```

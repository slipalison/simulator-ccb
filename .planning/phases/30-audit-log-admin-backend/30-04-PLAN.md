# Plan 30-04: Gap Closure — Corrigir URL de createAdmin() no Frontend

**Mode:** gap_closure
**Gap:** createAdmin() em admin-api.ts chama /api/admin/users (rota removida) em vez de /api/admin/administrators

## Objective

Corrigir a função `createAdmin()` em `frontend/backoffice/src/lib/admin-api.ts` para usar a URL correta `/api/admin/administrators`. A rota `/api/admin/users` foi renomeada para `/api/admin/administrators` no plano 30-02, mas o frontend não foi atualizado corretamente.

## Context

- **Gap detectado por:** VERIFICATION.md (re-verificação após plano 30-03)
- **Impacto:** Qualquer chamada a `createAdmin()` retorna 405 MethodNotAllowed em tempo de execução
- **Correção:** 2 linhas em 1 arquivo

<action>
No arquivo `frontend/backoffice/src/lib/admin-api.ts`:

1. Linha 314: alterar o comentário de:

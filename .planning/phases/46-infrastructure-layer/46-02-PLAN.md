**CedenteRepository** (implements ICedenteRepository):
- `AddAsync`: `_db.Cedentes.AddAsync(cedente, ct)` + `SaveChangesAsync`
- `SaveAsync`: `_db.Cedentes.Update(cedente)` + `SaveChangesAsync`
- `GetByIdAsync`: `_db.Cedentes.IgnoreQueryFilters().Include(c => c.TiposAtivo).FirstOrDefaultAsync(c => c.Id == id, ct)` — needs Include for TiposAtivo navigation
- `ExistsByDocumentoAsync`: Match on CedenteDocumento DU. The repository must query based on the document type:
  ```csharp
  public async Task<bool> ExistsByDocumentoAsync(CedenteDocumento documento, Guid companyId, CancellationToken ct = default)
  {
      return documento.Match(
          pf => _db.Cedentes.IgnoreQueryFilters()
              .AnyAsync(c => c.ClienteId == companyId && EF.Property<string>(c, "DocumentoTipo") == "PF"
                  && EF.Property<string>(c, "CpfValue") == pf.Cpf.Value, ct),
          pj => _db.Cedentes.IgnoreQueryFilters()
              .AnyAsync(c => c.ClienteId == companyId && EF.Property<string>(c, "DocumentoTipo") == "PJ"
                  && EF.Property<string>(c, "CnpjValue") == pj.Cnpj.Value, ct)
      );
  }
  ```
  Actually, since the Documento property is ignored by EF Core (we mapped via shadow properties in Plan 01), we need to query the shadow properties directly. Alternatively, we can simplify:
  - For PF: query by `CpfValue` shadow property where `DocumentoTipo == "PF"`
  - For PJ: query by `CnpjValue` shadow property where `DocumentoTipo == "PJ"`
  
  Use `EF.Property<string>(c, "DocumentoTipo")` and `EF.Property<string>(c, "CpfValue")`/`EF.Property<string>(c, "CnpjValue")` for the shadow property access.

  **Simpler approach (recommended):** Since the Documento property is ignored, query via shadow properties:
  ```csharp
  return documento.Match(
      pf => _db.Cedentes.IgnoreQueryFilters()
          .AnyAsync(c => c.ClienteId == companyId 
              && EF.Property<string>(c, "DocumentoTipo") == "PF"
              && EF.Property<string>(c, "CpfValue") == pf.Cpf.Value, ct),
      pj => _db.Cedentes.IgnoreQueryFilters()
          .AnyAsync(c => c.ClienteId == companyId 
              && EF.Property<string>(c, "DocumentoTipo") == "PJ"
              && EF.Property<string>(c, "CnpjValue") == pj.Cnpj.Value, ct)
  );
  ```

- `GetPagedByCompanyAsync`: `_db.Cedentes.IgnoreQueryFilters().Where(c => c.ClienteId == companyId).AsNoTracking()` + search on Nome + document (need to search via shadow properties CpfValue/CnpjValue)
  
  For the search in Cedente, extract digits from search string and search across Nome, CpfValue, and CnpjValue. Since Nome is a regular property and CpfValue/CnpjValue are shadow properties:
  ```csharp
  if (!string.IsNullOrWhiteSpace(search))
  {
      var normalized = search.Trim().ToLowerInvariant();
      var digitsOnly = new string(normalized.Where(char.IsDigit).ToArray());
      query = query.Where(c =>
          EF.Functions.ILike(c.Nome, $"%{normalized}%") ||
          (digitsOnly.Length > 0 && 
              (EF.Property<string>(c, "CpfValue").Contains(digitsOnly) ||
               EF.Property<string>(c, "CnpjValue").Contains(digitsOnly))));
  }
  ```

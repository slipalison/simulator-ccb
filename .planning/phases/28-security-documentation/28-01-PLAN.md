# Plan 28-01 — Security Documentation Consolidation + Compliance Mapping + Audit Checklist

## Overview

Final phase of Milestone v4.0. Consolidate all security documentation into a coherent reference set. Create a compliance mapping document that maps each security control to its requirement (OWASP, LGPD, CIS). Create an audit checklist for new contributors and PR reviewers.

## Success Criteria

1. ✅ `docs/security-overview.md` — Single entry point linking all security documents
2. ✅ `docs/compliance-mapping.md` — Maps each tool/control to OWASP Top 10, LGPD, CIS requirements
3. ✅ `docs/security-audit-checklist.md` — Checklist for PR reviewers and new contributor onboarding
4. ✅ All security docs cross-reference each other (no orphaned documents)
5. ✅ CONTRIBUTING.md security section links to the overview document

## Scope

### In Scope
- `docs/security-overview.md` — Navigation page for all security docs
- `docs/compliance-mapping.md` — Requirement-to-tool mapping
- `docs/security-audit-checklist.md` — PR review + onboarding checklists

### Out of Scope

### Audit Checklist

PR Review:
- [ ] All CI jobs pass (11 required checks)
- [ ] No new `// nosem` suppressions without justification
- [ ] No secrets committed (Gitleaks/TruffleHog pass)
- [ ] No dependency vulnerabilities introduced (Trivy/Dependabot clean)
- [ ] No IaC misconfigurations (Checkov passes)

New Contributor:
- [ ] Read CONTRIBUTING.md
- [ ] Read .github/SECURITY.md
- [ ] Install security tools locally (Semgrep, Gitleaks)
- [ ] Understand secret management (no hardcoded credentials)
- [ ] Know how to report vulnerabilities

# Milestone v7.0: PJ-Only Onboarding + Gestão de Funcionários

**Status:** ✅ SHIPPED 2026-05-01
**Phases:** 37-44
**Total Plans:** 19

## Overview

Transformar cadastro misto PF/PJ em PJ-only, onde PJ é usuário principal que gerencia funcionários PF com grupos de acesso, aceite de termos e auditoria completa. Isolamento entre empresas é requisito de primeira classe. Base zerada via docker compose down -v.

## Milestone Summary

**Key Decisions:**
- Cadastro PJ-only — PF removido completamente do fluxo
- Permissões via Keycloak groups nativo (NÃO Bit Flags no JWT)
- Grupos de acesso: admin-empresa, viewer, dashboard (seed automático) + custom groups (PERM-06)
- Default groups imutáveis — PJ pode criar/editar/deletar custom groups com qualquer combinação de permissões
- Isolamento entre empresas: HasQueryFilter + defense-in-depth application-level checks
- Base zerada: docker compose down -v
- AccessGroup como entidade no banco com permissões resource:action
- Keycloak group sync follows eventual consistency — DB is source of truth

**Issues Resolved:**
- GAP-6: RegisterEmployeeDialog criado — formulário completo de registro de funcionário

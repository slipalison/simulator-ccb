<task type="auto">
  <name>Task 1: Wire LoginPage with LoginForm, auth state, and redirect logic</name>
  <files>frontend/src/components/pages/LoginPage.tsx</files>
  <action>
    Replace the placeholder LoginPage with a working login page.

    LoginPage.tsx:
    - Wrap in PageLayout
    - Use useAuth() to get { login, auth }
    - State: `const [serverError, setServerError] = useState<string | null>(null)`
    - State: `const [isSubmitting, setIsSubmitting] = useState(false)`
    - Create handleLogin function:
      ```ts
      const handleLogin = async (data: LoginData) => {
        setServerError(null);
        setIsSubmitting(true);
        try {
          await login(data.email, data.password);
          navigate({ to: "/profile", replace: true });
        } catch (error) {
          if (error instanceof LoginError) {
            setServerError(error.message);
          } else {
            setServerError("An unexpected error occurred.");
          }
        } finally {
          setIsSubmitting(false);
        }
      };
      ```
    - Render `<LoginForm onSubmit={handleLogin} isSubmitting={isSubmitting} serverError={serverError} />`
    - If already authenticated (auth.isAuthenticated), redirect to /profile on mount

    What to avoid:
    - Don't catch and swallow errors silently — always set serverError
    - Don't redirect to / on login failure — stay on /login with error message
    - Don't show detailed error from backend — use generic messages only (SEC-08)
    - Don't clear form on error — let user correct their credentials
  </action>
  <verify>
    1. npx tsc --noEmit passes
    2. LoginPage renders LoginForm
    3. Invalid credentials → serverError displays "Invalid credentials."
    4. Valid credentials → navigate to /profile
  </verify>
  <done>LoginPage calls login() on submit, redirects on success, shows error on failure</done>
</task>

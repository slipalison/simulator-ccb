  <action>
**auth-code-flow.ts:** Criar com funções puras:
- generateCodeVerifier() → Uint8Array(32) via uncrypto webcrypto, base64url
- generateCodeChallenge(verifier) → SHA-256 via crypto.subtle.digest, base64url
- buildAuthorizationUrl({keycloakUrl, realm, clientId, redirectUri, codeChallenge, state})
- exchangeCodeForTokens({keycloakUrl, realm, clientId, clientSecret, code, codeVerifier, redirectUri}) → POST /token grant_type=authorization_code
- refreshAccessToken({keycloakUrl, realm, clientId, clientSecret, refreshToken}) → POST /token grant_type=refresh_token

**auth-server.ts:** Criar Vinxi h3 router com 5 rotas:
- GET /login: gera code_verifier + code_challenge + state, salva em cookies httpOnly (path /auth, maxAge 600), redirect 302 para Keycloak auth URL
- GET /callback: valida state, lê code_verifier, chama exchangeCodeForTokens, seta cookies httpOnly backoffice_access_token (maxAge 300) e backoffice_refresh_token (maxAge 28800), path /, Secure=false em dev, SameSite=Strict, limpa pkce cookies, redirect 302 para /admin/users
- GET /logout: deleta cookies access+refresh, redirect 302 para Keycloak OIDC logout (/realms/{realm}/protocol/openid-connect/logout?post_logout_redirect_uri={frontendUrl})
- GET /me: lê access_token cookie, decodifica JWT, retorna {adminName, email, isAuthenticated} ou 401
- POST /refresh: lê refresh_token cookie, chama refreshAccessToken, atualiza cookies

**app.config.ts:** Adicionar rota /auth delegando para auth-server.ts. Verificar padrão existente de server handlers no projeto.
  </action>

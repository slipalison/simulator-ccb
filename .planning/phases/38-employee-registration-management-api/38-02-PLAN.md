<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PJ → POST/PATCH/DELETE /api/companies/{companyId}/employees/* | Authenticated PJ (BearerClient) — company isolation enforced |
| PJ → GET /api/companies/{companyId}/employees | Company-scoped read — only own employees visible |
| Keycloak | User creation, block/unblock, password reset in realm "client" |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-07 | Elevation of Privilege | Employee CRUD endpoints | mitigate | Company isolation: verify route companyId == ICurrentCompanyService.CompanyId; if mismatch → 403 Forbidden |
| T-38-08 | Elevation of Privilege | Employee companyId verification | mitigate | Every handler checks employee.CompanyId == command.CompanyId before mutation — defense-in-depth beyond HasQueryFilter |
| T-38-09 | Information Disclosure | LGPD deletion | mitigate | Anonymize() sets PII to placeholder values before Keycloak deletion — no raw PII remains in DB |
| T-38-10 | Repudiation | All employee mutations | mitigate | Every action recorded via IAuditService with actor, target, timestamp |
| T-38-11 | Tampering | ChangeAccessGroup | mitigate | Verify new AccessGroup belongs to same company — prevent cross-company group assignment |
| T-38-12 | Spoofing | Temp password | mitigate | Cryptographic random via RandomNumberGenerator — not predictable |
</threat_model>

### ❌ Critical — Blocking Tests

**Issue 1: Registration API returns 500 (Tests 10, 11)**
- **Severity:** Critical — bloqueia todos os testes downstream (12, 14, 15, 18, 19)
- **Affected:** POST /api/registration (PF e PJ)
- **Symptom:** 500 Internal Server Error em vez de 201 Created
- **Suspected cause:** Possível erro na infraestrutura (DB connection, Keycloak Admin API, ou handler)
- **Next step:** Investigar logs da API com mais detalhe ou debugar RegistrationController
- **Gap for:** `/gsd:plan-phase --gaps`

**Issue 2: CNPJ validation returns 400 instead of 422 (Test 13b)**
- **Severity:** Medium — comportamento funcional correto, apenas status code errado
- **Expected:** 422 Unprocessable Entity
- **Actual:** 400 Bad Request
- **Cause:** ASP.NET Core model binding falha antes do FluentValidation para CNPJ inválido
- **Gap for:** `/gsd:plan-phase --gaps`

**Issue 3: Rider HTTP client variable resolution (Tests 18, 19)**
- **Severity:** Low — problema de tooling, não da API
- **Cause:** Rider executou todos os requests em batch, variáveis de resposta não foram capturadas
- **Fix:** Executar Test 15 isoladamente primeiro, depois 18/19 em sequência manual
- **Not a gap** — apenas ajuste de execução

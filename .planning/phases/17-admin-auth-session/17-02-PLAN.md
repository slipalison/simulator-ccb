# Phase 17 — Admin Auth & Session Management

## Plan 02: Frontend Admin Session, Refresh Interceptor & Error Handling

### Context

Plan 01 criou os endpoints backend para admin login/logout/me com cookies httpOnly. Agora o frontend precisa consumir esses endpoints e gerenciar a sessão admin com:
- Login page dedicada (/admin/login)
- Session restoration on page load
- Token refresh transparente (quando access token expira)
- Error handling global (401 → login, 403 → access denied, 5xx → toast)

**Existing infrastructure:**
- `auth-context.tsx` já implementa session restoration, refresh, memory-only tokens para usuários regulares
- `AuthGuard.tsx` já protege rotas verificando autenticação
- API client (`api.ts`) já tem funções `loginClient`, `refreshTokenClient`
- Toast infrastructure pode usar shadcn Toast (já instalado na Phase 12)

**Key differences for admin:**
- Admin AuthContext **separado** do user AuthContext (evitar conflitos de sessão)
- Admin usa cookies httpOnly (não Bearer tokens) — API calls devem incluir `credentials: 'include'`
- Admin tem páginas próprias (/admin/login, /admin/access-denied)
- Refresh strategy: ao invés de chamar `/api/auth/refresh`, chamar `/api/admin/auth/me` (que internally faz refresh)

### Requirements for this Plan

**ADMIN-07 — Transparent Token Refresh:**
- Middleware intercepta 401, usa refresh token para obter novo access token
- Retry automático da requisição original após refresh
- Se refresh falhar, session expirada → redirect para login

**ADMIN-08 — Session Restoration & Error Handling:**
- Ao carregar página, frontend chama `/api/auth/me` para verificar sessão
- 401 → redirect para `/admin/login` com toast "Sessão expirada"
- 403 → página de acesso negado "Você não tem permissão para acessar esta área"
- 5xx → toast genérico "Erro interno do servidor"

```typescript
export interface AdminSessionResponse {
  adminName: string;
  adminEmail: string;
}

export async function loginAdmin(email: string, password: string): Promise<AdminSessionResponse> {
  const response = await fetch('/api/admin/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password }),
    credentials: 'include', // Send/receive httpOnly cookies
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.detail || 'Login failed');
  }

  return response.json();
}

export async function logoutAdmin(): Promise<void> {
  await fetch('/api/admin/auth/logout', {
    method: 'POST',
    credentials: 'include',
  });
}

export async function getAdminMe(): Promise<AdminSessionResponse> {
  const response = await fetch('/api/admin/auth/me', {
    method: 'GET',
    credentials: 'include',
  });

  if (!response.ok) {
    throw new Error('Session invalid');
  }

  return response.json();
}
```

```typescript
interface AdminAuthValue {
  admin: {
    isAuthenticated: boolean;
    isLoading: boolean;
    adminName: string | null;
    adminEmail: string | null;
  };
  login: (email: string, password: string) => Promise<void>;
  logout: () => Promise<void>;
  restoreSession: () => Promise<boolean>;
}

// Module-level state (memory only — NO tokens)
let adminSession: {
  adminName: string | null;
  adminEmail: string | null;
} = { adminName: null, adminEmail: null };

export function AdminAuthProvider({ children }: { children: ReactNode }) {
  const [isAuthenticated, setIsAuthenticated] = useState(false);
  const [isLoading, setIsLoading] = useState(true);
  const [adminName, setAdminName] = useState<string | null>(null);
  const [adminEmail, setAdminEmail] = useState<string | null>(null);

  // Session restoration on mount
  useEffect(() => {
    async function tryRestore() {
      try {
        const me = await getAdminMe();
        adminSession = { adminName: me.adminName, adminEmail: me.adminEmail };
        setAdminName(me.adminName);
        setAdminEmail(me.adminEmail);
        setIsAuthenticated(true);
      } catch {
        // Session invalid
      } finally {
        setIsLoading(false);
      }
    }
    tryRestore();
  }, []);

  async function login(email: string, password: string) {
    setIsLoading(true);
    try {
      const session = await loginAdmin(email, password);
      adminSession = { adminName: session.adminName, adminEmail: session.adminEmail };
      setAdminName(session.adminName);
      setAdminEmail(session.adminEmail);
      setIsAuthenticated(true);
    } finally {
      setIsLoading(false);
    }
  }

  async function logout() {
    try {
      await logoutAdmin();
    } catch {
      // Best effort
    }
    adminSession = { adminName: null, adminEmail: null };
    setAdminName(null);
    setAdminEmail(null);
    setIsAuthenticated(false);
  }

  async function restoreSession(): Promise<boolean> {
    try {
      const me = await getAdminMe();
      adminSession = { adminName: me.adminName, adminEmail: me.adminEmail };
      setAdminName(me.adminName);
      setAdminEmail(me.adminEmail);
      setIsAuthenticated(true);
      return true;
    } catch {
      adminSession = { adminName: null, adminEmail: null };
      setAdminName(null);
      setAdminEmail(null);
      setIsAuthenticated(false);
      return false;
    }
  }

  return (
    <AdminAuthContext.Provider value={{
      admin: { isAuthenticated, isLoading, adminName, adminEmail },
      login,
      logout,
      restoreSession,
    }}>
      {children}
    </AdminAuthContext.Provider>
  );
}

export function useAdminAuth(): AdminAuthValue {
  const context = useContext(AdminAuthContext);
  if (!context) throw new Error('useAdminAuth must be used within AdminAuthProvider');
  return context;
}
```

```typescript
// Wrapper function for admin API calls that handles 401 automatically
export async function adminFetch(url: string, options: RequestInit = {}): Promise<Response> {
  const response = await fetch(url, {
    ...options,
    credentials: 'include', // Always send httpOnly cookies
  });

  if (response.status === 401) {
    // Session expired — try to refresh
    const { restoreSession } = await import('./admin-auth-context');
    const restored = await restoreSession();

    if (restored) {
      // Retry original request
      return fetch(url, {
        ...options,
        credentials: 'include',
      });
    } else {
      // Refresh failed — redirect to login
      window.location.href = '/admin/login?expired=true';
      throw new Error('Session expired');
    }
  }

  return response;
}
```

**Alternative approach (simpler):**
Ao invés de interceptor global, cada admin API call usa `try/catch` com verificação de 401:

```typescript
// In admin API client functions
export async function fetchAdminUsers(page: number, search: string) {
  try {
    const response = await fetch(`/api/admin/users?page=${page}&search=${search}`, {
      credentials: 'include',
    });

    if (response.status === 401) {
      // Redirect handled by error handler middleware
      throw new SessionExpiredError();
    }

    if (response.status === 403) {
      throw new AccessDeniedError();
    }

    return response.json();
  } catch (error) {
    if (error instanceof SessionExpiredError) {
      window.location.href = '/admin/login?expired=true';
    } else if (error instanceof AccessDeniedError) {
      window.location.href = '/admin/access-denied';
    } else {
      throw error;
    }
  }
}
```

**Decision:** Usar abordagem de error handling no Task 7 (mais simples e explícita)

#### Task 7: Error Handling Middleware (401/403/5xx)

```typescript
export class SessionExpiredError extends Error {
  constructor() {
    super('Session expired');
    this.name = 'SessionExpiredError';
  }
}

export class AccessDeniedError extends Error {
  constructor() {
    super('Access denied');
    this.name = 'AccessDeniedError';
  }
}

export async function handleAdminApiCall<T>(
  apiCall: () => Promise<Response>,
  toast: (opts: { title: string; description: string; variant?: string }) => void
): Promise<T> {
  try {
    const response = await apiCall();

    if (response.status === 401) {
      toast({
        title: 'Sessão expirada',
        description: 'Faça login novamente.',
        variant: 'destructive',
      });
      window.location.href = '/admin/login?expired=true';
      throw new SessionExpiredError();
    }

    if (response.status === 403) {
      window.location.href = '/admin/access-denied';
      throw new AccessDeniedError();
    }

    if (response.status >= 500) {
      toast({
        title: 'Erro interno',
        description: 'Erro interno do servidor, tente novamente mais tarde.',
        variant: 'destructive',
      });
      throw new Error('Server error');
    }

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    return response.json() as Promise<T>;
  } catch (error) {
    if (error instanceof SessionExpiredError || error instanceof AccessDeniedError) {
      throw error; // Already handled
    }
    throw error;
  }
}
```

**Usage example (in admin users page):**
```typescript
async function loadUsers() {
  setLoading(true);
  try {
    const data = await handleAdminApiCall(
      () => fetch('/api/admin/users?page=1', { credentials: 'include' }),

  } catch (error) {
    // Session expired or access denied — already handled
  } finally {
    setLoading(false);
  }
}
```

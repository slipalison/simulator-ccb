# Phase 11 — Plan 02: Forgot Password Flow (Resend.com)

## Objective

Implementar fluxo completo de recuperação de senha: usuário esqueceu a senha → solicita reset → recebe email com link → define nova senha → senha atualizada no Keycloak.

**Requisito atendido:** UX-05

## Execution Context

### Current State
- **Problema:** Sem mecanismo de recuperação de senha — usuário precisa contatar admin
- **Keycloak:** Admin API já configurada (`KeycloakUserService` com `manage-users` role)
- **Backend:** CQRS pattern com commands/queries, FluentValidation, DI manual
- **Frontend:** React Hook Form + Zod, Tailwind CSS, TanStack Router

### Technical Approach (Opção B — Resend.com)
```
1. Usuário clica "Esqueci minha senha" na LoginPage
2. Informa email em ForgotPasswordPage
3. Backend gera reset token (UUID + expiry 15min)
4. Backend envia email via Resend.com com link: /reset-password?token=xxx
5. Usuário clica link → ResetPasswordPage
6. Define nova senha + confirma
7. Backend valida token → atualiza senha via Keycloak Admin API
8. Redirect para /login com mensagem "Senha alterada com sucesso"
```

### Security Considerations
- **Information disclosure:** Forgot password com email inexistente retorna 200 genérico (mesma resposta que email existente)
- **Token expiry:** 15 minutos — após expiração, usuário precisa solicitar novo reset
- **Token single-use:** Após uso, token é invalidado (não pode ser reutilizado)
- **Password policy:** Nova senha deve atender política do Keycloak (min 8 chars, upper, lower, digit, special)
- **Rate limiting:** Máximo 3 requests de reset por hora por email (prevenção de abuso)

### Dependencies
- **Resend.com API key:** Free tier (3.000 emails/mês) — necessário configurar `RESEND_API_KEY` no `.env`
- **Keycloak Admin API:** Já configurada para update de senha
- **Database:** Tabela `password_reset_tokens` para armazenar tokens temporários (expiração automática)

   ```csharp
   public record ForgotPasswordCommand(string Email) : ICommand<Unit>;
   
   public class ForgotPasswordCommandHandler : ICommandHandler<ForgotPasswordCommand, Unit>
   {
       private readonly IPasswordResetTokenRepository _tokenRepo;
       private readonly IKeycloakUserService _keycloakService;
       private readonly IEmailService _emailService;  // Resend.com
       private readonly ILogger<ForgotPasswordCommandHandler> _logger;

       public async Task<Unit> Handle(ForgotPasswordCommand request, CancellationToken ct)
       {
           // 1. Verificar se email existe (sem revelar se existe ou não)
           var userExists = await _keycloakService.UserExistsByEmailAsync(request.Email);
           
           // 2. Se existe, criar token + enviar email
           if (userExists)
           {
               // Rate limiting check
               var recentTokens = await _tokenRepo.CountRecentTokensAsync(request.Email, TimeSpan.FromHours(1));
               if (recentTokens >= 3)
                   throw new RateLimitExceededException("Máximo 3 resets por hora");

               // Criar token
               var token = PasswordResetToken.Create(request.Email);
               await _tokenRepo.AddAsync(token);

               // Enviar email via Resend.com
               var resetLink = $"https://app.example.com/reset-password?token={token.Token}";
               await _emailService.SendPasswordResetEmailAsync(request.Email, resetLink);
               
               _logger.LogInformation("Password reset email sent to {Email}", request.Email);
           }
           else
           {
               // Mesmo log para não revelar se email existe
               _logger.LogInformation("Password reset requested for non-existing email: {Email}", request.Email);
           }

           // Sempre retorna sucesso (sem info disclosure)
           return Unit.Value;
       }
   }
   ```

4. **Criar `src/Onboarding.Application/Auth/Commands/ResetPasswordCommand.cs`:**
   ```csharp
   public record ResetPasswordCommand(string Token, string NewPassword) : ICommand<Unit>;
   
   public class ResetPasswordCommandHandler : ICommandHandler<ResetPasswordCommand, Unit>
   {
       private readonly IPasswordResetTokenRepository _tokenRepo;
       private readonly IKeycloakUserService _keycloakService;
       
       public async Task<Unit> Handle(ResetPasswordCommand request, CancellationToken ct)
       {
           // 1. Validar token
           var resetToken = await _tokenRepo.GetByTokenAsync(request.Token);
           if (resetToken == null)
               throw new BadRequestException("Token inválido");
           
           if (!resetToken.IsValid)
           {
               if (resetToken.IsExpired)
                   throw new BadRequestException("Token expirado");
               if (resetToken.IsUsed)
                   throw new BadRequestException("Token já utilizado");
           }

           // 2. Validar senha (password policy)
           if (!IsValidPassword(request.NewPassword))
               throw new ValidationException("Senha não atende política de segurança");

           // 3. Atualizar senha no Keycloak via Admin API
           var user = await _keycloakService.GetUserByEmailAsync(resetToken.Email);
           await _keycloakService.UpdateUserPasswordAsync(user.Id, request.NewPassword);

           // 4. Marcar token como usado
           resetToken.MarkAsUsed();
           await _tokenRepo.UpdateAsync(resetToken);

           return Unit.Value;
       }

       private bool IsValidPassword(string password)
       {
           // Min 8 chars, uppercase, lowercase, digit, special char
           return password.Length >= 8 
               && password.Any(char.IsUpper)
               && password.Any(char.IsLower)
               && password.Any(char.IsDigit)
               && password.Any(ch => !char.IsLetterOrDigit(ch));
       }
   }
   ```

     // Sempre retorna sucesso (sem info disclosure)
     return { ok: true };

   export const resetPasswordClient = async (token: string, newPassword: string) => {
     const response = await fetch('/api/auth/reset-password', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({ token, newPassword }),
     });
     
     if (!response.ok) {
       const error = await response.json();
       throw new Error(error.error);

     return { ok: true };

     const [password, setPassword] = useState('');
     const [confirmPassword, setConfirmPassword] = useState('');
     const [error, setError] = useState('');

     const searchParams = useSearchParams();

# Phase 19 — Plan 01: Frontend Client Migration

## Objective

Criar o projeto `frontend/client` como um projeto Vinxi independente e funcional, migrando todas as telas e componentes não-admin do monolith, validando que builda e roda na porta 5173 antes de prosseguir para o backoffice.

## Execution Context

**Strategy:** Copy-first-then-delete — NÃO deletar nada do `frontend/` original ainda. O monolith só será removido após o Plan 02 validar o backoffice.

**Port:** 5173 (mesma porta do frontend original — preserva compatibilidade)

**What migrates para client:**
- Pages: LoginPage, ProfilePage, ForgotPasswordPage, ResetPasswordPage, NotFoundPage
- Molecules: LoginForm, RegistrationForm, PasswordField, PasswordStrengthMeter, PersonTypeRadio, ProfileCard, KeycloakStatusBadge
- Atoms: ProfileBadge, ProfileField, ThemeToggle
- Organisms: Header
- Templates: AuthLayout
- Guards: AuthGuard
- Libs: auth-context.tsx, api.ts, types.ts, validation-schemas.ts, password-strength.ts, theme-provider.tsx, utils.ts, error-handler.ts, http-interceptor.ts
- UI: Todos os 13 componentes shadcn/ui
- Tests: Todos os testes não-admin

**What FICA no monolith (para Plan 02):**
- Admin pages, AdminLayout, AdminLoginForm, AdminUsersTable, AdminPagination, AdminStatusFilter, AdminSearchBar, UserDetailCard
- admin-auth-context.tsx, admin-api.ts, admin-error-handler.ts, admin-http-interceptor.ts
- Router com rotas admin

## Context

**Source:** `frontend/` monolith atual (D:\REPO\keycloak-tests\frontend\)

**Research findings:**
- Vinxi 0.5.x usa `createApp()` com 3 routers (public, api-proxy, client SPA)
- shadcn/ui tem 13 componentes stateless — copiar todos para cada projeto
- server.ts usa h3 para proxy `/api/*` → `http://api:8080` — idêntico em ambos os projetos
- Auth context e admin-auth-context já são separados — boa arquitetura
- ~25 arquivos de teste — dividir entre client e backoffice

**Prior decisions:**
- Code duplication acceptable, cross-imports forbidden
- Same dependency versions in both projects
- Fixed ports: client=5173, backoffice=5174

       - ./frontend/client/public:/app/public
       - ./frontend/client/server.ts:/app/server.ts
       - ./frontend/client/app.config.ts:/app/app.config.ts
